# Domain Glossary — 工地猜拳大賽（Construction Site RPS Adventure）

> 核心問題：**What do our domain terms mean? / 這些領域詞彙代表什麼？**
> 核心職責：**統一產品、設計、程式碼與測試中的領域語言，降低歧義；不新增需求、不重新規定驗收。**
> 依據：[PRD.md](../PRD.md)（產品意圖）、[spec.md](../spec.md)（正式行為與驗收 SSOT）、[technical-design.md](technical-design.md)（工程概念與暫定型別）
> 狀態：由既有已確認文件萃取的術語對照；若與權威文件不一致，依 [AGENTS.md](../AGENTS.md) 的變更控制協調，不以本表覆蓋規格。

## 使用原則

- 以本文的**領域意義**理解需求、命名、測試與交接；程式識別字可參考 Technical Design 的候選型別，但不將其草案視為必須逐字實作的 API 契約。
- 不把術語表變成第二份 FR／AC：詳細次數、事件流程、例外與驗收，直接連結至 Spec；產品範圍及優先級仍由 PRD 核准。
- 下列英文是開發時的共用術語，**不是新增遊戲文案**。對玩家顯示的文字仍須依 Spec 維持繁中／英文並列。

## A. 核心猜拳與模式

| 標準術語 | 領域意義與邊界 | 權威參考 |
|---|---|---|
| **手勢 / Gesture** | 猜拳輸入，只有 `rock`（✊ 石頭）、`scissors`（✌️ 剪刀）、`paper`（✋ 布）。英文 Paper 與中文「布」是**同一手勢**，沒有第四個手勢。 | [Spec §1](../spec.md) |
| **固定參賽主角 / Playable Character** | 三個固定手勢分別對應推推隊長／Captain Dozer、剪剪高手／Snip-Snip、蓋蓋吊車／Cover Crane；收藏解鎖不改動對應。 | [Spec §1、§7](../spec.md) |
| **一局／回合 / Round** | 一次完整的選拳、判定、呈現結果與完成流程；每局只有**一回合**，結束後可開始新局。不要解讀成三戰兩勝或多回合賽制。教學題亦以不同的教學回合計算。 | [Spec §3、§4](../spec.md) |
| **勝負結果 / Outcome** | 從指定玩家視角看的 `win`、`lose`、`tie`；平手沒有勝方。結果由手勢規則產生，不由角色、車速或動畫決定。 | [Spec §3.4](../spec.md)、[TD §5.1](technical-design.md) |
| **勝負關係 / Rule; RuleId** | 三條有勝方的規則：石頭贏剪刀、剪刀贏布、布贏石頭。技術設計的 `RuleId` **另含 `tie`**，但合格學習計數的 `MasteryRuleId` **不含 `tie`**。 | [Spec §3.4、§7.1](../spec.md)、[TD §5.1](technical-design.md) |
| **教學模式 / Learn** | 先公開對手手勢、詢問哪個手勢能贏，讓孩子學習規則；答錯是練習，不是正式對戰輸局。 | [Spec §3.1](../spec.md) |
| **電腦對戰 / Computer** | 對手手勢在揭曉前保密，並且**獨立於玩家選擇、等機率**隨機產生，不保證孩子贏。 | [Spec §3.2](../spec.md) |
| **親子同螢幕雙人 / Together** | Player 1（預設孩子）與 Player 2（預設家長）依序保密選拳，交接時不顯示前一人的已確認選擇；雙方確認後共同揭曉。 | [Spec §3.3](../spec.md) |

## B. 教學、計數與收藏

| 標準術語 | 領域意義與邊界 | 權威參考 |
|---|---|---|
| **教學題 / Learning Question** | 一個已知對手手勢及「什麼能贏它？」的問題；每個新教學回合最多產生一次合格學習計數。**題目公開對手手勢不算額外提示**。 | [Spec §3.1](../spec.md) |
| **選擇 vs 確認 / Selection vs Confirmed Attempt** | 點選手勢卡可自由重選；按「確認」才算一次有效作答／提交。一次教學題最多 **3 次確認作答**，不是最多點選三張卡。 | [Spec §3.1、§4](../spec.md) |
| **溫和提示 / Hint** | 第 1、2 次確認答錯後各給一次**不直接揭曉答案**的引導；第 3 次仍錯則揭曉並進入必要示範，**沒有第 4 次作答**。 | [Spec §3.1](../spec.md)、[AC-07.2](../spec.md) |
| **正確規則示範 / Demonstration** | 以正確獲勝手勢呈現勝負關係與因果說明。家長可主動「直接看示範」；第 3 次答錯則由系統**強制示範**，必要內容呈現完才可結束題目；資產失敗以完整靜態／簡化內容替代。兩者都不加計學習成績。 | [Spec §3.1、§4](../spec.md) |
| **合格首次無提示獨立答對 / Qualified First-Try Correct** | 新教學回合中，**首次確認即答對**且此前未接受額外提示或看答案，才為該條勝負關係加一次；同題重播、再次提交、提示後改對、看示範及普通對戰都不算。 | [Spec §3.1、§7.1](../spec.md) |
| **遊戲內掌握進度 / Mastery Counts** | 三條勝負關係各有一個獨立計數（0～3，最多計至 3），由合格首次無提示答對累積；不要求連續，不能把三條合併成總分。**遊戲內達標不等於已證實能在螢幕外猜拳**。 | [Spec §3.1、§7.1](../spec.md) |
| **混合出題 / Mixed Questions** | **三條規則分別都達到 3 次**合格答對（3/3/3）後才切換的教學出題階段；不是累積任意總共 3 次後切換。 | [Spec §3.1](../spec.md)、[AC-07.4](../spec.md) |
| **額外收藏車 / Collectible Vehicle** | 三位可出拳主角之外的 **3 台純收藏交通工具**；不作為第四手勢，也不替代三位固定參賽主角。具體車名／美術尚未定案。 | [Spec §7.1](../spec.md)、[PRD §4](../PRD.md) |
| **解鎖 / Unlock** | 每條勝負關係**各達第 3 次合格答對**才解鎖其對應的一台額外收藏車，且只發生一次。不是對戰勝利、累積遊玩次數、答錯後補答或示範的獎勵。 | [Spec §7.1](../spec.md)、[AC-11.1](../spec.md) |
| **短鼓勵 / Positive Feedback** | 完成回合、學習、示範、平手等情況可有短正向提示；**獲得鼓勵不代表解鎖或增加 Mastery Counts**。孩子正式對戰獲勝的完整愛的鼓勵掌聲是另一種回饋。 | [Spec §6.1](../spec.md) |

## C. 呈現與保存

| 標準術語 | 領域意義與邊界 | 權威參考 |
|---|---|---|
| **雙語畫面文字 / Bilingual On-screen Copy** | **所有畫面文字**固定以繁體中文及英文並列，包括按鈕、規則、設定；與語音設定無關。 | [Spec §6.2](../spec.md) |
| **語音語言模式 / Speech Language Mode** | 只控制語音：`bilingual`（預設，中文後英文）、`zh`（僅中文語音）、`en`（僅英文語音）；切換語音**不得把畫面文字改成單語**。這些值為 TD 的候選型別。 | [Spec §6.2](../spec.md)、[TD §9.1](technical-design.md) |
| **規則判定 vs 因果動畫 / Evaluation vs Causal Animation** | 判定先由手勢規則產生，動畫只**展示**已決定的規則；動畫、音訊失敗或重播不能改變結果、再次計數或再次解鎖。 | [Spec §4–§5](../spec.md)、[TD §6–§7](technical-design.md) |
| **本機進度 / Persisted Progress** | 需持久保存三組學習計數、已解鎖收藏及語音／音效偏好；**未完成回合與秘密選拳不持久保存**。本機資料不可用時仍可玩，但需告知可能無法保留。 | [Spec §7.2](../spec.md)、[TD §9](technical-design.md) |

**維護方式**：發現同一術語在文件、程式碼或測試中有不同含義時，先對照上述來源；涉及產品行為的歧義，須先修正權威的 Spec／PRD 並按 [AGENTS.md](../AGENTS.md) 同步更新本表，不以改名偷改規則。
