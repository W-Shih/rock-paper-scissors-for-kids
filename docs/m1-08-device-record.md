## 試玩方式與範圍

1. 用真正的 iPhone Safari 開啟部署紀錄中的 HTTPS 網址；不要使用通訊軟體內嵌瀏覽器。以直向開始。
2. 點「比賽 / Play」→「電腦 / Computer」→選手勢→確認→看倒數、對決及規則→完成→再玩一次→回首頁。
3. 重複遊玩，記錄實際遇到的勝／負／平手。電腦為公平亂數；未遇到的情境標 Not verified，不修改亂數強迫結果。
4. 在 iPad Safari 直向及橫向各執行一次；每種裝置／方向分開複製本表。

測試重點是 M1 Computer 切片。Learn／Together 仍為原型；Garage、家長設定、正式語音／掌聲、全部因果動畫及收藏仍有後續工作。**目前無正式音訊，聽不到聲音不可記成音訊驗收通過**。
網址可公開存取，但不是正式 MVP 發布；不填兒童姓名、照片、錄音或其他個資。若留截圖／操作影片，僅保留遊戲畫面及匿名觀察。進度只限同網址、同瀏覽器、同裝置；不要為測冷載入清除已有進度的網站資料。
